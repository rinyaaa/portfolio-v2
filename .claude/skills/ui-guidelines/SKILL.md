# UI実装の規範（タッチ操作・配色）

**このリポジトリの見た目の正はFigma**（`portfolio-design-source` スキル / CLAUDE.md §9.1）。色は下の初期パレットではなく、Figmaの値と `src/styles/` のトークン・SCSS変数から取る。**下の初期パレットはこのリポジトリでは使わない**（差し替え手順は他プロジェクトへ持ち出すとき用に残してある）。規範（下の「守ること」）はFigmaに書かれていない観点を埋めるものなので、そのまま適用する。

## タッチ操作への対応

- **ホバーだけで出す操作を作らない。** `:hover` / `group-hover` でしか現れない操作バー・メニュー・削除ボタンは、タッチ端末では触れない。**タップで開く導線を必ず用意する**
- ホバーを前提にした表示は、実装前に「ポインタを持たない端末で同じ操作ができるか」を確認する
- **アイコンだけのボタンは、タップ領域を44×44px以上にする。** 見た目のアイコンが小さくてもよいが、当たり判定を padding で広げる
- ホバーは「あると嬉しい」演出に留め、**操作の存在自体をホバーに隠さない**

## 配色で守ること

- **色はトークンとして定義し、コンポーネントに生の16進数を直接書かない。** 役割（本文 / 副次 / アクセント / 完了 / 保留 / 失敗）で名前を付ける
- **役割以外の用途に流用しない。** 「失敗」の色は失敗の表示だけに使う。削除ボタンのような「危険だが失敗ではない」ものには使わない
- **面を明度差だけで分けない。** 白と薄いグレーの差はコントラスト比にして約1.05:1しかなく、屋外や低輝度設定では消える。**面の区別は線と余白で作り**、強調は「濃い面 + 白文字」への反転で作る
- **補助テキストを薄くするために不透明度を下げない。** 薄くしたいときは「副次テキスト」の色を使う（不透明度は背景次第でコントラストが崩れる）
- **反転面のフォーカスリングを、その面と同じ色にしない。** リングが面に溶けて消える。白地のボタンなら地色のオフセットを挟み、濃色面なら白のリングを使う
- **濃色面（アクセント色などを面として塗った領域）では、白地用の色をそのまま使わない。** 濃色面専用の色を持つ
- ホバー色は一時的な演出なので面同士の差が小さくても許容するが、**区切り線や選択状態のような持続する表示には使わない**（状態は反転で示す）

## 初期パレット（プロジェクトで差し替える）

白地に対するコントラスト比を満たした初期値。**ブランドカラーが決まっているプロジェクトでは、下の「差し替え手順」に従って置き換える。**

| 役割 | 色 | 白地での比 |
| --- | --- | --- |
| 背景 | `#FFFFFF` | — |
| 本文・名前・アイコン | `#1C1917` | 17.5:1 |
| 副次テキスト・枠線・区切り線 | `#57534E` | 7.6:1 |
| アクセント（リンク・主要アクション・未読の強調） | `#3A34B5` | 9.0:1 |
| 完了（成功・処理済み） | `#065F46` | 7.7:1 |
| 保留（処理待ち・下書き） | `#78350F` | 9.1:1 |
| 失敗（エラーのみ） | `#991B1B` | 8.3:1 |
| 識別色（アバター等、対象ごとに色を振る用途） | `#115E59` / `#9D174D` / `#3A34B5` | 7.6〜9.0:1 |

濃色面（アクセント色や本文色を面として塗ったサイドバー等）の上では上表は成立しないので、専用の色を使う。

| 役割 | 色 | 比 |
| --- | --- | --- |
| 濃色面の本文・反転テキスト | `#FFFFFF` | `#3A34B5` 地で 9.0:1 / `#1C1917` 地で 17.5:1 |
| 濃色面の副次テキスト・線・バッジの面 | `#C7C4E8` | `#3A34B5` 地で 5.3:1 |
| アクセントの押下・ホバー（面／文字） | `#2A2585` | 上に白文字で 12.3:1 / 白地の文字として 12.3:1 |

補足:

- 「本文・名前・アイコン」の `#1C1917` は、選択中の項目や反転ボタンの**面**としても使う。その面のホバーは `#57534E`（上に白文字で 7.6:1）
- 濃色面では `#57534E` の線は 1.2:1 で見えない。濃色面の線は `#C7C4E8` を使う

## 差し替え手順

1. 役割の一覧（背景 / 本文 / 副次 / アクセント / 完了 / 保留 / 失敗）は変えない。**色だけを差し替える**
2. 差し替えた色ごとに、使う地色に対するコントラスト比を計算する。**本文・アイコンは 4.5:1 以上、大きな文字と境界線は 3:1 以上**（WCAG 2.1 AA）。上の初期値は余裕を持って7:1以上にしてある
3. 比はブラウザのDevTools（要素を選ぶとContrast ratioが出る）か、任意のコントラスト計算ツールで確認する。**目視で判断しない**
4. アクセント色を面として使うなら、その上に載る白文字・線・ホバーの3色も同時に決める（決めないと濃色面で必ず破綻する）
5. 決まった値を `CLAUDE.md`（またはデザイントークンのファイル）に表として書き、このスキルの表ではなくそちらを正とする
