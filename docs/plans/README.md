# 計画書

- 欄は スコープ / スコープ外 / 受け入れ条件 に揃えておくと、`implementation-review` が差分と突き合わせるときに読みやすい
- 検討途中のメモや作業ログはここに置かない（作業ログは `docs/history/`）
- Claude Codeのプランモードが作る計画は `~/.claude/plans/` にセッション単位で保存されるもので、ここには残らない
